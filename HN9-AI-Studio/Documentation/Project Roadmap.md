# Project Roadmap — HN9 AI Studio

## Vision
An AI-powered content generation platform that produces Instagram Reels, YouTube Shorts, LinkedIn
posts, blogs, images, voiceovers, AI videos and marketing assets from a single brand source of truth.

## Phases

### Phase 1 — Foundation
- [ ] Finalize brand source of truth (`/Brand`).
- [ ] Establish prompt library standards (`/Prompts`).
- [ ] Define the agent fleet (`/Agents`).

### Phase 2 — Pipeline
- [ ] Wire agents into automation workflows (`/Workflows`).
- [ ] Build content templates (`/Templates`).
- [ ] Set up asset and output management (`/Assets`, `/Output`).

### Phase 3 — Application
- [ ] Backend orchestration API (`/Backend`).
- [ ] Frontend content studio (`/Frontend`).
- [ ] Operational dashboard (`/Dashboard`).

### Phase 4 — Scale
- [ ] Multi-brand / multi-client support.
- [ ] Analytics and feedback loops.
- [ ] Additional channels and agents.
